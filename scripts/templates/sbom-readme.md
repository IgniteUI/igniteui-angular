## Scope

The **delivered** documents describe exactly what a consuming application resolves: the `igniteui-angular` package plus the transitive closure of its runtime `dependencies` and the `peerDependencies` it requires at runtime. Development-only packages are excluded, because they are never installed by consumers and never reach a production bundle. These are the documents to feed a vulnerability scanner or a compliance review of the shipped product.

The **build environment** document is a supplementary, best-effort view of the repository dependency tree, including development and build-time tooling. npm dependency-tree errors are tolerated for this document and are recorded below. It exists to answer supply-chain provenance questions and is deliberately *not* an inventory of what ships to customers.

Components in the delivered documents are enumerated from evidence - the installed package tree - not from declared ranges. CycloneDX and SPDX npm package identities are compared before either document is attested.

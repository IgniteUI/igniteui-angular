## Scope

The **delivered** documents describe exactly what a consuming application resolves: the
`igniteui-angular` package plus the transitive closure of its runtime `dependencies` and the
`peerDependencies` it requires at runtime. Development-only packages are excluded, because they
are never installed by consumers and never reach a production bundle. This is the document to
feed a vulnerability scanner or a compliance review of the shipped product.

The **build environment** document describes the full dependency tree of the repository that
produced the artifact, including development and build-time tooling. It exists to answer
supply-chain provenance questions (SLSA, secure-development questionnaires) and is deliberately
*not* an inventory of what ships to customers.

Components are enumerated from evidence — the installed package tree — not from declared ranges.
